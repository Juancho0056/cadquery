# Arquitectura
Flujo: config → components → mechanisms/assembly → validation → exporters/visualization.
Sólidos en coordenadas locales, mm; ensamblaje y fabricación usan transformaciones independientes. Interfaces futuras declaran identificador, versión, puertos, ejes, tolerancias, material, orientación, restricciones y estado de validación. Los módulos vacíos son reservas, no funcionalidades.
