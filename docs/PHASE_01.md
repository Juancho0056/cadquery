# Fase 01 — protocolo de inspección
Entrada: archivos originales locales Knuckle_Joint__v2.3mf y hand+ratchet+pla+only.3mf. No incluir en Git sin permiso.
1. Registrar SHA256, autor, URL, versión, licencia y permisos.
2. Inspeccionar ZIP/3MF, unidades, objetos, transformaciones, placas y mallas; distinguir piezas de soportes.
3. Medir cotas reales, interfaces, ejes, dientes, uñas, selector y retenciones.
4. Identificar trayectoria de carga y modo de fallo de cada componente.
5. Documentar A/B/C y transición bajo carga; no inferir seguridad de un render.
6. Seleccionar qué reutilizar, componer, extender o crear.
Salida: inventario verificable y ADR de cartucho. Estado: NOT_RUN, originales pendientes.
