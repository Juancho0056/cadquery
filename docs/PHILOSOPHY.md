# Filosofía de diseño mecánico
Planificar → Probar → Implementar → Revisar → Verificar → Aprender.
Reutilizar → Componer → Extender → Crear.

Priorizar geometría, enclavamiento positivo, integración funcional, montaje sin herramientas, reparación y diseño paramétrico. No eliminar componentes externos si ello compromete seguridad, resistencia o vida útil. Separar las funciones de guía, retención, transmisión y liberación. Considerar anisotropía FDM, fluencia, fatiga, orientación y tolerancias. No certificar resistencia sin ensayo físico.

Estados: conceptual, prototipo CAD, verificado geométricamente, ensayado físicamente, aprobado para una aplicación definida.
