# ADR-0030 — Codo compacto indexado
Alcance V2 restringido a uniones y codos; accesorios aplazados. Primer codo de horquilla con disco Ø48, eje Ø8 y pasador angular Ø5 a radio 17, posiciones cada 30°, rango experimental ±90°. Ambos extremos usan el puerto universal existente. Se elige bloqueo positivo manual antes de intentar trinquete automático. No se acredita retención axial de los pasadores ni recorrido libre, ni se afirma que sea un mecanismo de botón. Pruebas de siete poses, bloqueo y rechazo de ángulo no indexado. CI pendiente; pueden existir interferencias. No apto para carga.
