# ADR-0035 — V3 pulsador axial central
Se conserva V2 y se crea feature/modular-arm-v3. Diseño propio basado en principio genérico de embrague de dientes axiales, no reproducción de un archivo MakerWorld. Se elimina pasador excéntrico, torre, guía y clip de eje como arquitectura objetivo. Cuatro sólidos nominales: horquilla, rotor, pulsador dentado y tapa inferior; volumen reservado para quinto componente, resorte comercial. La horquilla contiene guía estriada inferior, el rotor contiene perfil compatible y apoyo anular inferior. Pulsar 7 mm retira dientes del rotor, dejando guía fija engranada. Posiciones cada 30°. La tapa todavía no tiene fijación ni soporte lateral para el resorte; no existe retorno físico modelado, retención axial superior definitiva ni secuencia de montaje certificada. Se prueban poses y obstrucción angular; no se afirma funcionamiento automático. Mantener alcance exclusivamente uniones/codos. No apto para carga.
