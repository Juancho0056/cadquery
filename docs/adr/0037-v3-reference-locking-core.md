# ADR-0037 — Núcleo concéntrico basado en referencia funcional
Referencia: marvelousun, Spring-loaded, self-locking joint mechanism, https://www.thingiverse.com/thing:7168674, CC BY-NC según LICENSE.txt del ZIP aportado. README describe émbolo con engranaje y retorno por anillo metálico deformado. No se incluyen ni copian mallas originales; geometría paramétrica propia. Se mantiene el prototipo de horquilla V3 anterior como comparación y se construye banco del núcleo concéntrico: ocho lóbulos de transición suave muestreada, R14/18, diámetro de carcasa 60, engrane axial nominal 6, carrera 7, copa fija con cámara de resorte. El espacio de resorte y estimación lineal usan hipótesis de OD18, longitud libre 23, sólida 5 y tasa 0.8 N/mm; no se seleccionó producto ni se modeló espira real. El banco no contiene retención axial del rotor, topes de pulsador, apoyos independientes ni puertos: no es un conjunto ensamblable definitivo. Pruebas de poses axiales, giro liberado, obstrucción positiva y dimensiones. No se afirma radio de raíz exacto, retorno automático, resistencia o certificación. No apto para carga.
