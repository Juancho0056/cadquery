# ADR-0038 — Apoyo y retención independientes
Banco del núcleo: camisa exterior integrada, holgura radial nominal 0.35 mm y anillo superior desmontable con cuatro taladros M3 y pilotos en camisa. El anillo limita extracción del rotor sin usar el émbolo como eje estructural. Diámetro exterior 68 mm, decisión provisional para alojar camisa y fijaciones. No se modelan tornillos ni se garantiza resistencia de pared alrededor de pilotos; requiere revisar fijación y montaje. No se incorpora todavía tope superior del émbolo. Se mantienen dientes del núcleo anterior. Se añaden pruebas de interferencia y captura axial/radial. CI pendiente. No apto para carga.
