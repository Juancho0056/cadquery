# ADR-0040 — Montaje axial y retorno
Base 3c0ea6b: CI 262/262 PASS (45873950736). Se añade modelo de referencia helicoidal OD18, alambre 0.8 y 6 vueltas, y envolventes nominales M3x8. No es selección comercial ni cálculo validado de constante elástica; no se afirma contacto efectivo de extremos o vida útil. Los pilotos Ø2.3 intersectan intencionalmente envolvente de rosca Ø3; el material, tornillos e inserción deben calificarse físicamente. Se añade barrido de inserción axial superior en pasos de 2 mm, con rotor indexado, y auditoría de interferencias del resorte y fijaciones. No se agregan piezas impresas ni se cambian dientes. CI pendiente. No apto para carga.
