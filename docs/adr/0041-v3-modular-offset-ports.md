# ADR-0041 — Puertos integrales del codo V3
Base ad12f17: evidencia local Windows Python 3.12.5, CadQuery 2.8.0, 5/5 montaje y 63/63 V3; 204 deseleccionadas. Se reutiliza interfaz rectangular V2 sin alterar el núcleo ni los ocho dientes. El rotor incorpora un puente axial elevado para librar retenedor y cabezas M3, la carcasa fija incorpora cuello inferior. Boca a 70 mm del eje, centros Z2.2 y Z29.5; desfase axial 27.3 mm provisional, no es un codo coplanar. No se afirma resistencia de la transición ni montaje completo del retenedor con el rotor extendido: el anillo cerrado podría requerir introducirse antes del rotor o rediseño. Se auditan poses, plugs, tornillos y trayectoria del rotor; CI pendiente. No apto para carga.
