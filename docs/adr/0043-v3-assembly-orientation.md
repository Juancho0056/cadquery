# ADR-0043 — Orientación obligatoria de montaje
Evidencia local 4566f29: 47/49 PASS. Se corrigieron las seis interferencias de plegado. Inserción lateral a 45° y 90° colisiona con puente (5.4781303 y 128.7083150 mm³). Se prescribe montaje a 0°, puente paralelo al corte del retenedor, antes de instalar tornillos y conectores. 180° también se audita como alternativa geométrica. No se modifica geometría ni se exige montaje en cualquier ángulo de servicio. Los dos casos fallidos permanecen como controles negativos explícitos; no se relaja umbral. Auditoría de ambas mitades secuenciales incluyendo mitad instalada, muestreo 1 mm; movimiento posterior muestreado cada 10°. No acredita movimiento continuo, montaje físico ni resistencia. CI pendiente.
