# ADR-0047 — Conservar brazo de referencia
Se inspecciona ARM_updated_stls.zip del usuario, 40 STL binarios. No se redistribuyen. Obj1 tiene sección exterior ~24.8 en Z1..80 y ~28 en Z100; obj3 tiene cuello cilíndrico Ø12 en Z20.1..34.9, centro XY (778.7141,151.75377), diámetro medido 11.9964..12.0001; tramo largo presenta geometría roscada. Obj5 presenta envolvente ~28.7 en Z50..120. No se ha establecido relación cinemática completa entre piezas. Se implementa lector de STL y medición reproducible, y probeta de guía giratoria Ø12 con holgura radial 0.25; no es conexión estructural, no se une todavía al codo ni se modifica original. Se evita bloquear giro del husillo sin saber función. Ensayos físicos y licencia pendientes. No apto para carga.
