# ADR-0048 — Integración de terminales originales
Base 93104e1: evidencia local 46/46 PASS. Inspección directa del ZIP: obj1 lengüeta de espesor X11.5, orificio transversal a X con sección Y148.206..158.206 Z118.3..128.3 (Ø10, centro Z123.3); extremo Z133.3. Obj5 horquilla con caras interiores X140.89 y152.09 (gap11.2), orejas de 8 mm y sección de orificio de primera oreja Y146.488..156.485 Z5..15; segunda oreja presenta sección no idéntica, requiere confirmar coaxialidad y paso efectivo. Se implementan contrapartes integrales de prueba: horquilla A gap12.1, lengua B espesor10.6, bore10.4, galga9.8. El husillo Ø12 no se utiliza como soporte. No se redistribuyen STL. Se prueba conjunto propio sin mallas originales en 10 poses hasta ±90°, y galgas nominales. La unión real con originales, paso de pasador en segunda oreja, retención del pasador, recorrido angular con brazos instalados, extensión y resistencia no acreditados. No se restringe API base V4 ni se afirma plegado completo del conjunto adaptado. CI pendiente. No apto para carga.
