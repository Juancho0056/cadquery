# ADR-0049 — Vista local de terminales originales y control de orificios
Base e9c3b30: evidencia usuario 12/12 terminales y 58/58 V4 local. Reapertura ZIP original: obj1 y obj5 son mallas cerradas. Secciones X obj5 134–140 presentan contorno interior nominal Ø10, pero X155–160 presentan contornos menores y desplazados; no se puede certificar galga Ø9.8 común. Se incorpora transformación rígida de mallas originales a centros de pasadores V4, sin modificar STL fuente; exportación local de piezas separadas para cargar juntas preservando posiciones en laminador. Auditoría de distancia mínima en secciones discretas y paridad de material en centro nominal. No constituye auditoría volumétrica ni garantía de ajuste. Obj1/obj5 son terminales originales separados, no se afirma que constituyan un brazo extensible completo. No se incluye ZIP en Git. No se cambia núcleo ni terminales CAD hasta inspección de acople. CI pendiente; no apto para carga.
