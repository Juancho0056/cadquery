# ADR-0055 — Reconstruir la envolvente antes de mecanizar
El usuario confirma que el brazo debe formar parte del cuerpo, y las capturas de 131715a muestran protuberancias por superposición de cuello anterior y loft. Se reemplaza la construcción de joint_half por un blank completamente nuevo: arco circular R28 tangente a curvas Bezier en planta, envolvente transversal de secciones de rectángulo redondeado que evolucionan a sección casi circular. No se utiliza neck() en esta ruta. Se reutilizan las operaciones canónicas fixed/moving aceptando blank opcional; llamadas antiguas sin cambios. Se mide directamente el ZIP en cortes: obj1 Z103/104.9/105.1 aproximadamente Ø27.9, obj5 Z39.9/40.1/42 aproximadamente Ø27.9, contorno único en esas secciones. El terminal CAD tiene aproximadamente 27.88 mm y área ~611 mm². Prueba local de la geometría equivalente con CadQuery: ambos sólidos válidos; diferencia de núcleo Ø56 nula en ambas direcciones; poses 0, ±45, ±90 y 30 liberada sin interferencia. Se detectaron colisiones CAD A/B a 135° (33.17 mm³) y 180° (2760.54 mm³). Se mantienen como controles negativos, no se acredita recorrido completo ni se altera API angular; exportación sigue rechazando interferencias. La continuidad tangencial en planta se construye geométricamente; no se declara continuidad global G1/G2 ni resistencia. Backend manifold3d no disponible localmente, por lo que unión con STL y auditoría protegida requieren ejecución del usuario. Se conserva desfase 15.4 mm y núcleo. Exportación segregada intacta. No apto para carga.
