# ADR-0059 — Regresión de límites de offset
Usuario aporta ejecución 6130dc8: 37 PASS, 6 FAIL. Cinco fallos por 11.7-15.4/2 = 3.999999999999999 frente al límite 4. Se retorna CENTER_Z exacto para offset nominal. Sexto fallo: el test asumía colisión de carcasas CAD alineadas a 180°, pero OCC reportó volumen 0. No se declara plegado válido ni se invierte la expectativa para aprobarlo. Se sustituye esa hipótesis por control analítico de envolventes longitudinales cilíndricas y control positivo de detección. El estudio de mallas completas sigue siendo necesario; no se cambia geometría ni tolerancia de interferencia. Usuario observa posible debilidad en transiciones; antes de elegir offset se requiere evaluar sección resistente, carga, extensión y ensayos. No apto para carga. Nueva ejecución estricta pendiente.
