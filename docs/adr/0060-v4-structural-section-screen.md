# ADR-0060 — Evaluación geométrica de secciones resistentes
Usuario confirma 45/45 PASS en 77.95 s, con RuntimeWarning convertido en error, base 0ab26de. Se añade integración de secciones planas trianguladas de los cuellos mecanizados CAD: área, centroide, inercias Iy/Iz, producto Iyz y módulos resistentes por ejes globales. Muestreo radial 28..45 mm, cuatro offsets. Controles analíticos rectángulo, círculo y anillo hueco, y dos variantes reales. No se impone umbral arbitrario de resistencia: faltan cargas, material efectivo impreso y condiciones de apoyo. No es FEA, no mide concentración de tensiones, torsión, unión STL, dientes, fatiga o resistencia física. No se modifica geometría. Seis pruebas escritas, ejecución local pendiente. No apto para carga.
