# ADR-0061 — Refuerzo localizado en cuello B
Informe usuario: 144 secciones, Wy mínimo B 1090.588 mm³ a X27.99, A 2194.679 mm³ a X-45.01 (offset15.4). Variar offset no mejora apreciablemente el mínimo Wy. Se añade variante opcional de envolvente transversal reconstruida B con crecimiento superior de 4 o 6 mm, desde X24, máximo X28..32, decrece hasta X44. Se permite aumento exterior localizado dentro del radio 28, pero se conserva funcionalidad dentro de R23.5 y terminal nominal; no se modifica dentado, A ni número de piezas. Default 0 para preservar línea base. Meta de cribado Wy mínimo 2000 mm³, no garantía de carga ni resultado obtenido. Estudio compara secciones y poses integradas con bloqueo/liberación; no exige plegado imposible ni certifica movimiento continuo. Diez pruebas escritas; aún no ejecutadas contra CAD/STL. No se afirma mejora real hasta medir. Resistencia, extensión y hardware no acreditados.
