# ADR-0062 — Envolvente superior de pendiente controlada
Capturas de 4809212 muestran cresta en transición B. Se sustituye distribución previa por techo cúbico exacto en planta XZ, con pendientes nulas en nodos X24,32,46 y altura terminal original. Los perfiles del loft se derivan del techo; intersección final con envolvente Bézier impide sobrepasarlo. No se garantiza continuidad global de superficie ni ausencia de irregularidades inferiores. Se conserva variante anterior en commit 4809212, baseline sin refuerzo intacta, API y CLI sin cambios. Se añaden ocho pruebas de cotas, pendientes, geometría real, núcleo y mejora mínima relativa del 20% de Wy en secciones muestreadas. Objetivo absoluto 2000 sigue siendo objetivo, no resultado. No se ejecutaron CAD/STL en esta intervención; comprobar pruebas, informe estructural y poses antes de elegir. No apto para carga.
