# ADR-0063 — Alternativa de ejes rectos
Solicitud usuario: eliminar curvas verticales y aceptar brazos desfasados. Se añade alternativa --straight, sin alterar default anterior. Dos cilindros rectos de radio13.94 desde |X|24 a48, integrados con discos canónicos y mecanizados originales. Ejes Z-2.5 y26.5, separación 29 mm, holgura nominal entre cilindros 1.12 mm; no garantiza plegado porque carcasas y salientes originales pueden interferir. Unión directa disco/cilindro sin fillet inicial, para evaluar concepto antes de optimizar raíz. No se afirma resistencia de la raíz ni auto-soporte: orientación tubo abajo/articulación arriba en STL de impresión, posible voladizo importante en disco. Se conservan controles booleanos y preservación STL. Siete pruebas escritas, no ejecutadas. No apto para carga.
