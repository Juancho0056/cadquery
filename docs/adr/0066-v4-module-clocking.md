# ADR-0066 — Orientación radial común
Usuario aclara que el saliente forma parte del bloqueo telescópico y que el tubo perforado debe conservar su orientación relativa. Se añade rotación cardinal común en marco local X a los cuerpos originales recortados obj1 y obj5, antes de unir con las carcasas. CLI --flush --clocking 180, default 0 preservado. Transformación reutilizable para los demás miembros cuando estén registrados en el mismo marco local; no se ha identificado ni ensamblado todo el conjunto de 40 STL, ni se afirma compatibilidad de guías, perforaciones y pasador en todas las extensiones. Medición directa ZIP: obj1 radio transversal X 13.95 mm; obj5 extremos X relativos al centro -14.3545/+20.6405 mm. Tras inversión, separación teórica axial de cuerpos longitudinales ~0.0955 mm (28.4-13.95-14.3545), insuficiente como tolerancia física certificada. No se cambia carcasa ni mecanismo, no se espejo geometría. Se mantiene rechazo de interferencias, diagnóstico acepta clocking. Diez pruebas escritas, booleanos no ejecutados por ausencia de manifold3d. No apto para carga.
