# ADR-0068 — Cribado de hardware antes de aligerar
Se conserva geometría flush clocking180 con rampas. Se añade auditoría CAD del espacio del resorte y pulsador en tres carreras y de retención nominal mediante desplazamiento axial de galgas. Resorte de ejemplo OD18, libre23, sólida5, k0.8 N/mm es hipótesis heredada Core, no SKU ni recomendación de compra. Margen provisional de altura sólida 1 mm. Retenedor nominal: galga Ø2.4×5.8, agujero Ø2.5, penetración radial 1 mm, holgura al fondo .5 mm; no modela rosca ni garantiza extracción bajo carga. No aligerar hasta comprobar resultados. Tres pruebas escritas, sin ejecutar. No apto para carga.
