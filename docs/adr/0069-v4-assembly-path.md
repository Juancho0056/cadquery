# ADR-0069 — Secuencia de montaje nominal
Se conserva geometría flush, clocking180, rampas y alojamiento de resorte. Se añade cribado de inserción axial resorte, pulsador y carcasa móvil y radial de tres galgas, comprobación de acceso exterior y tope positivo del pulsador. Resorte representado por envolvente cilíndrica Ø16, no SKU. Muestreo discreto, no certificación de recorrido continuo, precarga, montaje físico, herramientas reales o tolerancias. Las colisiones se informan y CLI retorna 1; no se alteran geometrías para ocultarlas. Se usan carcasas CAD, no cuerpos STL completos. Tres pruebas escritas, no ejecutadas. Se pospone aligeramiento hasta evidencia de montaje y fabricación.
