# ADR-0072 — Impresión vertical y probeta funcional
Evidencia local: comparación de 34 orientaciones. Vertical A 1097.36 mm² candidatos, base proxy 391.76 mm², altura 178.99; vertical B 1310.28, base proxy 9.27, altura 179.68. B tilt30 up reduce área apenas 0.87% y base proxy cero. Se conserva vertical como orientación candidata, no certificación de resistencia. Se añade probeta de articulación recortando únicamente extremo distal de las carcasas CAD a ±38 mm, sin alterar dentado, ranura, pulsador ni alojamiento de resorte. No requiere ZIP. No es brazo completo ni ensayo de carga; permite ensayar ajuste y montaje con hardware real y mismo material/perímetros. Dos pruebas escritas no ejecutadas. No se modifica modelo productivo.
