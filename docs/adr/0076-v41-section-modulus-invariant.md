# ADR-0076 — Corrección de invariante del cribado estructural
Evidencia local: 2/3 pruebas, fallo de Wy=1.0011269345164586 respecto a espiga sin perforar. JSON del usuario: área 284.585→199.258 mm², Iy 5632.493→5413.203 mm⁴, Iz 7538.672→4738.300 mm⁴, Wy 615.771→616.465 mm³, Wz 753.868→485.176 mm³, ambos brazos. La sección D cambia de centroide y distancia a fibra extrema; Wy no es monótono bajo sustracción. Se sustituye la premisa inválida por disminución estricta de momentos centroidales y verificación independiente de Wy=Iy/c con tolerancia relativa 0.2% por teselación. Se mantiene comprobación de pérdida de área y Wz. No se altera geometría ni se enmascara el resultado. No es certificación de resistencia. Pruebas corregidas pendientes de ejecución local.
