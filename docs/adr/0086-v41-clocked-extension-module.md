# ADR-0086 — Variante radial A independiente
Informe usuario ADR0085: offset14.75 fase60, 26/26 índices0..12 con obstrucción bilateral; 0/25 muestras plegadas libres. Se mantiene bloqueo candidato. Rotar cuerpo original A 180° alrededor de su eje longitudinal, no alrededor del origen global. Fusionar espiga D canónica sin rotarla; preservar cuerpo fuera de zona de unión. Rotar contraparte exterior y tornillo juntos. No alterar cabezal, botón, hardware M4 ni módulo B. Comparar baseline y variante en índices0/6/12 ambos lados y ángulos0/90/180 (54 muestras). Exportar previews de variante índice12 únicamente si libres. No afirmar trayectoria continua ni fuerza; pruebas y booleanas pendientes locales.
