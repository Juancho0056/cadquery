# ADR-0088 — Cadena modular extensible
Usuario requiere agregar articulaciones y segmentos, no terminar obligatoriamente en extremos dentados. Informe anterior B90/270: 36/36 muestras 0/90 libres, 0/18 plegadas; residuo máximo 58.236/56.738 mm³. Se suspende búsqueda radial. Reutilizar m.arm(1) y m.arm(5) como dos mitades del mismo segmento, cada una con espiga D canónica. Registrar por transformación rígida usando datums originales ya verificados. N articulaciones requieren N+1 segmentos; extremos libres macho D para futuros accesorios hembra. Cada articulación conserva cabezales, botón, M4 y retenes. Tornillos longitudinales en offset14.75 fase60 candidato. Primera variante misma mano: escalonamiento acumulado 28.4 mm por articulación, no decisión final; estudiar alternancia y separación luego. Ocho muestras de cadenas 3/4 segmentos, índice6, incluye plegados diagnósticos. No modificar geometrías ni afirmar carga, movimiento continuo o impresión definitiva. Pruebas y booleanas pendientes en equipo usuario.
