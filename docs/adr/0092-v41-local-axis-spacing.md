# ADR-0092 — Separación local de ejes
Campaña rápida optimizada completa: 48/52 muestras libres, ±165 última muestra libre, ±180 colisión, tres segmentos índice6. No ejecutar otra campaña global antes de corregir interferencia local. Variante independiente: crecer caras exteriores de cada cabezal delta, eje A baja delta/2, B sube delta/2, distancia 28.4+delta. Plano de acoplamiento, núcleo, retención y dientes conservados mediante operaciones originales; ranura D y taladro M4 trasladados con eje; prolongar solo extremo del pulsador y barreno superior. Conservar tubos, usar orientación exterior A previamente ensayada, extremos D libres. Comparar delta0..4 mm, descartar al primer defecto, comprobar nueve combinaciones de inserción plegadas y muestras rectas/intermedias con botón liberado. Sin modificar módulos canónicos; resultados y pruebas pendientes locales. No confundir cero penetración con holgura positiva ni con plegado global o carga segura.
