# ADR-0094 — Kit imprimible de ajuste
Usuario solicita imprimir último diseño. Reutilizar variante local 29.4 y cadena alternada sin cambios geométricos. Kit por defecto dos segmentos, una articulación, 7 tipos STL, nueve piezas físicas. Auditar recta solicitada y plegada si dos segmentos. Separar STL individuales de hardware de preview; cantidades y dimensiones en manifest. Orientación vertical candidata, PETG parámetros iniciales, sin calificación física. No base/garra aún. Exportación requiere ZIP original local y dependencias; no redistribuir referencias. No ejecutar campaña extensa. Pruebas pendientes localmente.
