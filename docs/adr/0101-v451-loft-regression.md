# ADR-0101 — Revertir loft interpolado
El usuario reporta Null TopoDS_Shape al cortar socket D en upper V4.5.1. Restaurar loft reglado de V4.5, cuya geometría se generó localmente. Mantener correcciones de pulsador, retenedores, rosca y agarre. Causa sospechada, no confirmada: interpolación del loft y su efecto sobre booleanas. Validación CAD local pendiente.
