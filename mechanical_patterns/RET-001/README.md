# RET-001 — Probeta de retención axial anular
Objetivo: estudiar dos nervios anulares de un eje que giran dentro de ranuras de una carcasa partida. La carcasa se monta radialmente; requiere contención externa temporal (por ejemplo, sostener manualmente las mitades durante una prueba de giro sin carga). No es una unión autónoma ni el diseño definitivo del brazo. Un mecanismo de cierre de carcasa será una iteración posterior.

Holgura radial y axial por lado: 0.20, 0.30 y 0.40 mm. Eje Ø12 mm, nervios Ø14.4 mm, ancho 2.4 mm. Longitud 24 mm. Las tolerancias son hipótesis experimentales, no valores universales.

## Prueba física
1. Imprimir una variante primero, registrar material, orientación, altura de capa y dimensiones reales.
2. Montar las mitades radialmente, mantenerlas juntas y girar el eje sin carga.
3. Medir juego axial; observar interferencias, desgaste y facilidad de montaje.
4. Repetir con las demás variantes. No realizar ensayo de carga sin un dispositivo que contenga las mitades de forma segura.
5. Registrar resultados y elegir la holgura según la aplicación.

Exportar con `python mechanical_patterns/RET-001/model.py`.
